A **full-featured E-commerce platform** built with the **MERN Stack** and styled with **Tailwind CSS**.  
Designed not just to function, but to impress — combining clean UI, seamless user experience, and solid performance.  

🔗 **[Live Demo](https://e-commerce-app-full-1.onrender.com)**  

---

## ✨ Features  

- 🔑 **Authentication** – Register/Login with validation  
- 🛍️ **Product Filtering** – Filter by categories & brands  
- ↕️ **Product Sorting** – Sort by price & alphabetical order  
- 🛒 **Cart Management** – Add, remove, and update items in cart  
- 💳 **Integrated PayPal Payments** – Secure checkout system  
- ⚙️ **Admin Panel** – Add/Edit products and manage inventory  
- 📦 **Order Tracking** – Get real-time order status  
- 🌙 **Dark Mode Support** – Fully responsive modern design

## 🚀 Installation & Setup  

Clone the repository:  

```bash
git clone https://github.com/ADNUKUNHOME/E-COMMERCE-APP-FULL.git
cd E-COMMERCE-APP-FULL

🔹 Backend Setup
cd server
npm install
npm run dev

🔹 Frontend Setup
cd client
npm install
npm start
```

## 🔹 Environment Variables

### client/.env  
```bash
VITE_API_URL=http://your-backend-baseurl.com
```

### server/.env
```bash
CLIENT_BASE_URL=http://your-frontend-baseurl.com
CLIENT_SECRET_KEY=**********
CLOUD_NAME=*******
CLOUDINARY_API_KEY=********
CLOUDINARY_API_SECRET=********
MONGO_URI=*********
PAYPAL_CLIENT_SECRET=********
PAYPAL_CLIENT_ID=********
PORT=5000
```
